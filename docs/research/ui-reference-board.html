Homepage & search

Show the size of the catalog, then send people to search

The two directories you pointed to both open with a count, one search box, and quick ways to narrow the list.

  • aixploria.comopened
    Hero with a live tool count. A category dropdown shows a count for each category, plus pricing chips (Verified, Free, Freemium, Paid). A trust line reads "72 categories · updated daily · manually verified". Ranked lists follow: Latest, Our selection, Top in category.
  • aitoolsdirectory.comopened
    Submit, Advertise and Deals buttons sit in the header. Exactly two "Featured Tool" cards, then a filter bar (keyword, name, category, price), then "Showing 1–100 of 779" above a 6-column grid.
  • futuretools.ioopened
    A ranked "Top 20" list with a movement arrow on each row. Featured status is a badge on a row, not a separate banner.
For this project: keep the current section order. Add a trust line under the search box and counts on the category tiles. Featured vendors go in one labelled row only.

Category directory

Filters that matter to Thai buyers, plus a map view

The B2B sites use a filter sidebar with counts. The AI directories use a single filter bar. With 113 vendors, either works; the filter choices matter more than where they sit.

  • SourceForge categoryopened
    Left sidebar with a count on each filter: features, deployment, free trial, integrations, API, organization size, Regions. Sort by Sponsored, Rating or Reviews. Each card shows rank, logo, vendor, rating and starting price.
  • aitoolsdirectory.comopened
    Each card has an image, name, pricing pill, 4 category tags that link to their category pages, a description and a full-width Details button.
  • G2 categoryblocks bots
    A Compare checkbox on each card fills a tray at the bottom. A buyer's guide and FAQ sit below the list.
  • MartechMap / chiefmartec
    A landscape view: each category is a box full of vendor logos. Shows the whole ecosystem at a glance.
For this project: filter by LINE integration, Thai UI, local presence, company size, pricing model and verified status. Add a List / Landscape toggle, which works well for an expo audience.

Vendor profile

Make verification part of the page header

Product Hunt and SaaSHub both use a header with actions, tabs, and a sidebar of facts. Neither shows when a listing was last verified. This project can, because the data model already stores evidence and a verification status for each claim.

  • Product Hunt product pageopened
    Logo, tagline, rating and followers, with Visit, Follow, Add to collection and Share. Tabs: Overview, Reviews, Alternatives, Customers, Team. The sidebar has company links, founding year and awards.
  • SaaSHub profileopened
    Breadcrumb, then Visit, Alternatives, Save, Verify and Edit buttons. Sections: listed in, screenshots, features, badges, summary of public mentions, alternatives.
  • aitoolsdirectory tool pageopened
    TRY IT button, pricing pill, tags, features list, then "Alternatives to X" with a one-line comparison for each.
For this project: put the verification badge and "last verified" date in the header. Add tabs for Capabilities, Integrations, Thai customers and Alternatives, and a Suggest a correction link that sets "Correction needed".

Compare (up to 3)

Compare in a table, then contact the vendors

The bottom tray "Shortlist 0 · Compare 0/3" on the current site already follows the G2 and Capterra pattern. What's missing is a good table page and a next step at the end of it.

  • G2 Compareblocks bots
    Products are picked from a category, then "Compare Now". The product headers stay fixed at the top; rows hold scores, features, pricing and satisfaction. Up to 4 products (docs).
  • Capterra compareblocks bots
    Each column has a logo, rating and Visit button. Rows: pricing, free trial, deployment, features (✓ / –).
  • StackShare stackupsrate-limited
    Side-by-side description, pros and cons, integrations.
For this project: group the rows (overview, capabilities, Thai market fit, pricing, verification). Add a Show only differences toggle. End each column with Contact provider, which starts a consented lead.

Shortlist & member area

Go from saved vendors to one brief sent to all of them

Saving is easy on every reference site. None of them carries saved vendors through to the "Connect" step, which your four-step flow already promises.

  • aixploriaopened
    A heart on every card, and a favorites icon with a count in the header.
  • Product Hunt collectionsopened
    "Add to collection" saves into named, shareable lists.
  • Capterra Shortlistblocks bots
    Saved products with a compare action.
For this project: visitors save without signing in, and the list moves to their account when they sign in (member_saved_vendors already exists). The member page goes Saved → Compare selected → Send brief.

Buyer's Guide 2027

Show what's inside, then ask for the details

HubSpot's report page is a well-made example of a gated download that people still fill in.

  • HubSpot State of Marketingopened
    Cover image, 2 headline stats as a teaser, a "What's inside" list of 3 chapters, a 5-field form, a consent line under the button, one quote, and a link to last year's report.
  • PDPA consent guidance
    Consent must be explicit, given at or before collection, and must name any third-party sharing.
For this project: use the same structure. Link the existing /buyer-guide/preview route as "Read chapter 1". Each provider gets its own unticked consent box; newsletter and demo consent stay separate.

Summary

What to copy first

  1. A labelled featured row above the free grid

    aitoolsdirectory. Keeps paid placements visibly apart, which protects the independence claim.

  2. Verification badge and "last verified" date on every card and profile

    No reference site does this well. It is the platform's clearest way to stand out.

  3. Compare tray → sticky compare table → "Contact selected providers"

    Turns browsing into consented leads, which is the Connect step.

  4. Category tiles with counts, and a landscape-map view

    aixploria's counts plus MartechMap's logo boxes. Suits the expo audience.

  5. Gated guide with a stats teaser and a "What's inside" list

    HubSpot's structure, with a consent box for each provider.

Research date: 16 Nov 2026. Sites marked "blocks bots" refused automated access, so their notes come from help docs and their public descriptions. Open them yourself to check the current layouts. Every number in the wireframes is a placeholder.
